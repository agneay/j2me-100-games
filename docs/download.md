# Download

Every game is published as its own GitHub Release with a JAR and a JAD file. Most phones only need the **JAR**; the JAD is the descriptor used for over-the-air (OTA) installs and by some emulators.

**All games in one archive:** [j2me-100-games-v1.0.0.zip](https://github.com/agneay/j2me-100-games/releases/download/v1.0.0/j2me-100-games-v1.0.0.zip) (all 100 JAR + JAD pairs, the license and the install guide).

Browser demos for every game are on the [website](https://agneay.github.io/j2me-100-games). See [installing.md](installing.md) for help.
